# Pre-registration index

The only run in this directory that counts as confirmatory is the evaluation of the computable
bound on the 88 saved networks. Its pre-registration is `PREREG_T2.md`, frozen with this file in
`PREREG_FREEZE.json` before that evaluation. Everything else here (Theorem 2 checks, restricted
Rayleigh-Ritz lower bounds, the exact penalty bias) is deterministic, network-free computation that
needs no pre-registration; it is checked by independent formulas as described in each script.
